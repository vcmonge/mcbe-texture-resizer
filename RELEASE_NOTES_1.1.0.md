# Iron 1.1.0

## What's new

- Added support for `_n` normal maps.
- Added support for `_mers` metallic/emissive/roughness maps.
- All matching map variants are now associated and resized when multiple variants coexist.

## Requirements

- Windows
- Java 25

## Download

Download `iron-1.1.0-windows.jar` and run:

```powershell
java --enable-native-access=ALL-UNNAMED -jar iron-1.1.0-windows.jar
```

Back up your resource pack before processing: resized textures overwrite the
original files in place.
